Bamboo Fun CTE-450 — standalone Windows Ink driver

Запуск
1. Подключите Wacom Bamboo Fun CTE-450 по USB.
2. Запустите run-bamboo-driver.vbs в корне проекта.
   Для переносного архива: распакуйте его и запустите BambooDriver.exe.
3. Драйвер автоматически включается и появляется в системном трее, без окна
   на панели задач. По умолчанию используется основной монитор.
4. Двойной щелчок по значку открывает настройки. Чтобы выбрать другой монитор,
   нажмите «Остановить», выберите монитор и снова нажмите «Запустить».
   Индикатор показывает нажим в диапазоне 0–511.
5. В приложении для рисования выберите Windows Ink и включите зависимость размера
   кисти от нажима. Драйвер должен оставаться запущенным во время рисования.

«Свернуть в трей», сворачивание и крестик окна скрывают настройки и сохраняют
работу драйвера. Окно настроек тоже не добавляется на панель задач.
В меню значка трея доступны «Открыть настройки» и «Остановить и выйти».
«Остановить» и выход через меню освобождают устройство и восстанавливают
прежний режим планшета.
Для проверки только аппаратного нажима снимите флажок Windows Ink перед запуском.

Возможности
- Прямое чтение HID-пакетов CTE-450 (USB VID 056A, PID 0017).
- Координаты, 512 уровней давления, контакт, приближение и уход пера.
- Передача пера, нажима, ластика и боковой кнопки через Windows Ink.
- Выбор монитора, включая мониторы с отрицательными координатами.
- Работа без установки собственного драйвера ядра и без изменения защиты Windows.

Ограничения
Это пользовательская программа-драйвер для Windows 10 1809+ / Windows 11 x64.
Она предоставляет Windows Ink; собственная реализация WinTab не входит в неё.
Программы, принимающие только WinTab, могут не получить нажим.
Сенсорное кольцо и четыре кнопки на корпусе пока не назначаются.
Наклон не передаётся: эта модель не сообщает его в поддержанном протоколе.
При запуске другого драйвера того же планшета возможен конфликт доступа.
В программы, запущенные от администратора, обычный процесс может не передать ввод.
После аварийного завершения, если планшет перестал двигать курсор, отключите и
повторно подключите USB: это сбросит аппаратный режим.

Сборка и проверки
Исходный код: tools/bamboo-driver/BambooDriver.cs.
Сборка: powershell -NoProfile -File tools/bamboo-driver/build.ps1
Иконка генерируется из векторной геометрии (16–256 px) и встраивается в EXE.
Компилятор: .NET Framework 4.x x64, штатно присутствующий на этой Windows 11.
Результат: target/bamboo-driver/BambooDriver.exe.
--self-test: проверка формата HID, давления, координат и ABI Windows.
--probe: открытие реального планшета, включение и восстановление режима, без ввода.
--ink-test: короткий тест Windows Ink в собственном видимом тестовом окне.
Журнал: %LOCALAPPDATA%/BambooCTE450/driver.log.
