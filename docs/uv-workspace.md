# UV-развёртка

Откройте GLB-модель из каталога двойным щелчком. В меню режима над 3D-видом выберите **«UV-развёртка»** — пункт находится под «Редактирование».

Слева остаётся 3D-модель, справа плавно открывается UV-карта. Объекты модели выбираются в дереве или щелчком в 3D-виде. Активный объект указан в инспекторе.

## Автоматическая развёртка

Нажмите **«Авторазвёртка»** в верхней панели. PartUV Geometric автоматически выбирает разрезы и параметризует поверхность через ABF. Для упаковки полученных островов используется xatlas; повторное вычисление швов при упаковке не выполняется.

Расчёт идёт в отдельном процессе, интерфейс остаётся доступным. Инспектор показывает этап, время и плавный индикатор активности. «Отменить расчёт» или Esc останавливают процесс и оставляют исходные UV. Если объект изменён или удалён во время расчёта, устаревший результат не применяется.

Развёртка выполняется встроенным движком Rust + C++ на CPU. Python, pip, uv, CUDA и AI-веса для UV не требуются. Редактор содержит готовый нативный процессор и необходимые библиотеки; при запуске ничего не скачивается. Готовые компоненты и рабочие логи находятся в `%LOCALAPPDATA%/BevyEditor/uv-runtime`; папка тестового сравнения алгоритмов не используется.

Инспектор разделён на блоки «Развёртка», «Атлас», «Просмотр» и «Изменения». Подробные пояснения появляются при наведении на кнопки, заголовки и подписи параметров. В UV-режиме «Окружение» изначально свёрнуто; нажмите заголовок, чтобы открыть настройки света и фона. Состояние этого раздела хранится отдельно от обычного просмотра модели.

Перед запуском можно выбрать:

- **Точнее**, **Баланс** или **Меньше швов** — ограничение искажений PartUV 1,1 / 1,25 / 1,5.
- Размер целевого атласа: 1024², 2048² или 4096².
- Отступ между островами: 4, 8 или 16 пикселей.

Размер является ориентиром упаковщика при расчёте плотности; UV-координаты нормализованы в диапазон 0–1. Изображение текстуры автоматически не создаётся.

## Просмотр и ручная правка

- **Шахматная текстура** помогает увидеть растяжение на 3D-модели; это только отображение, материалы GLB не заменяются.
- **Швы** показывают границы островов на модели.
- **До / после** переключает исходную карту и результат последней развёртки/упаковки без изменения документа. После последующих UV-правок сравнение становится недоступным.
- ЛКМ выбирает остров; Shift добавляет или исключает его из выделения. Щелчок по поверхности модели выбирает соответствующий остров.
- Перетаскивание выделенного острова перемещает UV. Одна законченная операция перетаскивания — один шаг Undo.
- Панель над картой: **«Все · A»**, **«Снять»**, **«90°»**, **«− / +»** для выделения, поворота и масштаба островов активного объекта.
- **«Упаковать»** повторно размещает текущие острова с выбранным отступом, сохраняя их швы.
- Колесо приближает UV под курсором. СКМ или Пробел + ЛКМ перемещают карту. **F** над картой вписывает диапазон 0–1.
- В 3D-виде остаются Alt+ЛКМ для орбиты и СКМ для панорамы.

Инспектор показывает число островов, суммарную площадь UV и количество граней за пределами 0–1. Площадь — сумма площадей UV-треугольников, а не проверка отсутствия перекрытий. У карт с намеренно наложенными островами значение может превышать 100%.

## Сохранение и ограничения

Результат появляется в документе, но не перезаписывает файл автоматически. **Ctrl+Z** отменяет его, **Ctrl+Shift+Z / Ctrl+Y** возвращают, **Ctrl+S** сохраняет UV в исходный GLB через обычную систему сохранения модели. Сцена проекта и другие экземпляры модели не меняются до сохранения ассета.

Редактируется основной канал **UV0**. Положения вершин, нормали, цвета, материалы и UV1 сохраняются. Если новый шов проходит по диагонали исходного многоугольника, только такой многоугольник разбивается на треугольники: поверхность остаётся той же. Одновременно рассчитывается один активный объект; геометрические инструменты в UV-режиме отключены.

Автоматическая развёртка поддерживает до 500 000 треугольников на объект в рамках общего лимита редактора на число вершин. Это не замена художественной расстановке швов: лицо и другие заметные области стоит проверить перед текстурированием.

Упаковка учитывает реальные контуры островов, включая очень узкие треугольники. Острова остаются целыми; поворот, перенос и общий равномерный масштаб сохраняют их форму и относительную плотность текстуры. Дополнительный поиск размещения выбирает более плотный корректный результат. При ошибке проверки доступна запасная упаковка по прямоугольникам. Действует ограничение редактора моделей: сетки со скелетом и morph targets пока доступны только для просмотра.

## Разработка и проверка

- `native/uv/src` — подготовка неманифолдных рёбер и дерево частей Ward на Rust.
- `native/uv/cpp` и `native/uv/vendor/partuv` — прямой вызов C++ PartUV/ABF и xatlas, проверка происхождения углов и защита формы островов.
- `native/uv-build` — воспроизводимая сборка и включение движка в редактор. Заголовки зависимостей поставляются в проекте с контрольной суммой.
- `src/editor/model_uv_backend.rs` — распаковка встроенных компонентов, отменяемый нативный процесс и JSON-протокол.
- `src/editor/model_uv_mesh.rs` — UV-топология и обновление углов без замены геометрии.
- `src/editor/model_uv{,_ui,_view,_input}.rs` — документ, интерфейс, GPU-атлас и ввод.

`BEVY_EDITOR_UV_HOME` меняет место хранения готового движка и рабочих логов. `BEVY_EDITOR_UV_WORKER` позволяет разработчику указать другой нативный процессор. При сборке `BEVY_EDITOR_UV_NATIVE_DIR` позволяет использовать заранее собранный каталог с процессором и его библиотеками. Переменные не нужны для обычного запуска.

Проверки:

```powershell
cargo test --lib uv_
cargo test --lib uv_partuv_real_worker -- --nocapture
cargo test --lib gpu_uv_workspace -- --ignored --nocapture
cargo test --lib uv_native_
```

Сборка процессора отдельно: `cargo build --manifest-path native/uv/Cargo.toml --release`. Сравнение качества на одинаковом JSON-входе описано в `native/uv/README.md`.

GPU-проверка использует временную копию проекта. Для локальной проверки персонажа задайте `BEVY_EDITOR_UV_QA_MODEL` — путь к GLB. Скриншоты сохраняются в `target/uv-qa`; пользовательские модели в репозиторий не добавляются.

PartUV Geometric использует базовую геометрическую часть PartUV. AI-сегментация PartField и её веса не устанавливаются и не запускаются. Лицензии сторонних компонентов указаны в `ATTRIBUTION.md` и в исходниках нативного движка.
