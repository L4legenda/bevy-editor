# Уплотнение UV-атласа

Проверка 17 ноября 2026: тот же персонаж, 23 755 треугольников, режим «Баланс», атлас 2048², отступ 8 px.

## Результат

| Метрика | До изменения | Новая авторазвёртка |
| --- | ---: | ---: |
| Суммарная площадь UV | 28,2034% | 42,9103% |
| Острова по топологии движка | 136 | 136 |
| Угловое искажение p95 | 1,059264629 | 1,059264629 |
| Угловое искажение p99 | 1,098961664 | 1,098961664 |
| Грани вне 0–1 | 0 | 0 |

Заполнение выросло на 14,71 процентного пункта, или примерно на 52,1% относительно исходного. Сам алгоритм PartUV, его разбиение и параметры ABF не менялись.

Отдельная повторная упаковка прежней готовой карты дала 40,1447% вместо 28,2034%. Она сохраняет все 136 исходных островов: независимая проверка нашла единое преобразование подобия для каждого острова с максимальным отклонением 0,000000711 UV, то есть менее 0,002 пикселя при 2048². Относительный разброс измеренного масштаба менее 0,009% обусловлен float32 и очень маленькими островами. В самом упаковщике применяется один общий масштаб.

Независимая проверка пересечений треугольников между островами дала 0 и для авторазвёртки, и для повторной упаковки. Площадь UV сама по себе не является доказательством отсутствия перекрытий.

Прежняя карта содержала почти схлопнутые микроскопические острова. В новой упаковке они сохраняют свою форму и общую плотность. Поэтому эвристический подсчёт швов с фиксированным допуском 1e-6 и число визуально объединённых островов в старом инспекторе могут отличаться; новые разрезы не добавляются. Для сравнения разбиения используется исходная топология островов, а не этот абсолютный допуск.

## Изменения

- Упаковка реальных контуров с сохранением переданных островов, включая узкие и вырожденные соединения.
- Исключена независимая подгонка ширины и высоты острова к пиксельной сетке.
- Поворот восстанавливается по всем вершинам, а не по одному потенциально вырожденному треугольнику; применяется общий равномерный масштаб.
- Координаты каждого острова предварительно сдвигаются ближе к нулю для устойчивых вычислений.
- Исправлен случай нулевой оси convex hull у маленьких островов: для них используются исходные оси, остальные продолжают упаковываться по контуру.
- Проверяются несколько вариантов ориентации, включая разворот части островов на 180°. Выбирается корректный вариант с большей площадью.
- Поиск по сетке ограничен 16 384 кандидатами на остров; при необходимости используется обычный поиск xatlas. Полный перебор давал около 51% на этом персонаже, но занимал минуты; финальный вариант использует ограниченный поиск.

## Проверки

Пройдены 6 нативных тестов: подготовка геометрии, вогнутый остров с заполнением свободной области маленькими островами, узкие соединения, удалённый от начала координат маленький остров и независимый детектор пересечений.

Пройдены все 13 проверок редактора по фильтру `uv_`; отдельный GPU-тест выполнен явно. `cargo build --locked --offline --bin bevy-editor -j4` завершился успешно; готовая сборка — `target/debug/bevy-editor.exe`. Для устранения блокировавшей сборку ошибки нового формата сцен преобразование ошибок при дублировании сцены приведено к строке в `browser_duplicate.rs`.

Полный GPU-тест редактора с финальным нативным процессором прошёл: авторазвёртка, сравнение, выбор и перенос островов, Undo/Redo, отмена, повторная упаковка и сохранение GLB. Сцена проекта и её история не изменились. Для GPU-теста использован BEVY_EDITOR_UV_WORKER, указывающий на финальный процессор; совпадение встроенного экземпляра с ним проверяется по SHA-256 в bundle-verification.json.

Сохранённый GLB повторно открыт независимым Rust-декодером. Сохранились 23 755 треугольников, все 12 334 уникальные позиции и площадь поверхности. UV конечны и находятся в 0–1. После повторной упаковки в этом сценарии площадь UV составила 43,20%.

Артефакты: `target/uv-pack-qa/auto-quality.json`, `repack-check.json`, `auto-layout-check.json`, `native-tests-bounded.log`, `editor-gpu-final.log`, `saved-glb-check.json`, `bundle-verification.json`. Сборка приложения и проверки UV редактора записаны в `editor-build-final.log` и `editor-tests-complete.log`.
